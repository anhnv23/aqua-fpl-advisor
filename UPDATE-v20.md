# Cập nhật Aqua FPL Advisor v20

Ghi đè toàn bộ mã nguồn v19 bằng nội dung gói v20 rồi deploy lại Netlify.

Không cần thay đổi Environment Variables hoặc OpenAI API key. Backend tiếp tục dùng FPL API để tải đội hình chính thức của từng Gameweek.

Sau khi Netlify báo **Published**, mở website và tải lại mạnh bằng `Ctrl + F5`.
