# Cập nhật Aqua FPL Advisor v21

Ghi đè toàn bộ mã nguồn v20 bằng nội dung gói v21 rồi deploy lại Netlify.

Không cần thay đổi Environment Variables hoặc OpenAI API key. Backend tự lấy điểm cầu thủ từ endpoint live của FPL theo từng Gameweek.

Sau khi Netlify báo **Published**, mở website và tải lại mạnh bằng `Ctrl + F5`.
